## 一、它是什么

一个**可运行的择偶定位评估系统**：用户填条件表单（可传照片），系统按博主「鳌烨（月老鳌烨）」的公开内容输出评分、择偶窗口、该放弃的幻想项与提升建议。

**它同时是一个「知道自己每句话有多少依据」的系统**——每条结论带证据强度标签，每份报告第一行是数据来源声明。

## 二、必须最先知道的三件事

### 1. 所有证据来自**同一家机构**

报告的**第一行**就是这句（不可折叠、随 API JSON 走）：

> 本系统的全部证据来自同一商业机构（鳌烨传媒）的公开内容。所有强度标签指的是「该机构内多个账号一致表述」，不代表跨机构或第三方独立验证。

**如果按「整个鳌烨矩阵 = 1 个来源」计算，159 条规则里没有一条是「已验证」的。** 这不是缺陷描述，是语料的事实。

### 2. 结论正确率**当前不可测**（这是结论，不是未完成项）

原因有两层：

| 层 | 说明 |
|---|---|
| **结构性错配** | 案例来自博主**口头问出来的条件**，产品需要用户**自填表单**——「博主不会问『你觉得自己情绪稳定度几分』」 |
| 分母为零 | 45 条案例平均缺 23/29 个必填项；严格口径下可评估案例 **0 条** |

**所以：不得对外声称任何准确率。** 此前出现过的 75.6% / 68.9% / 17.8% / 15.6% **全部撤回**。

### 3. 强度标签怎么读

| 标签 | 真实含义 | 能否进计算 |
|---|---|---|
| **机构内多源一致** | 该机构多个账号说法一致（**不是第三方验证**） | ✅ |
| **机构内 2 源一致** | 同上，2 个账号 | ✅ |
| **机构内单源** | 只有 1 个账号说过 | ❌ 只展示 |
| **外部可核验** | **你可以自己去查那个数据**（如国家统计局） | ✅ 不受账号数限制 |
| 外推参考 | 由相近人群规则外推，误差不可估计 | ⚠️ 显示但不进综合分 |
| 工程默认 | 无语料依据 | ❌ 不得进结论 |
| 体系参考 | 规则标记为仅供人工阅读 | ❌ 只展示 |

**报告里默认只显示绿/蓝/红三种标记；数量最多的「机构内单源」收在行尾「▸ 来源」里，点开可看完整依据。**

## 三、已知的局限（不要当成 bug，是已知事实）

1. **证据多样性受限于语料来源。** 100+ 个账号里绝大多数是同一批内容的矩阵分发。**V3 语料从 1511 条涨到 3533 条（3.5×），净提级 = 0 条。**
2. **40.3% 的语料是直播切片**（1424/3533，`aoye28` 自身占 71.5%）。**「有多少条视频说了某件事」反映的是切片密度，不是他说过多少次。**
3. **8 种「假独立」形式**中，**2 种确认无法自动检测**：
   - 同品牌**口头禅回响**（短句标签式跨 host 复用）→ 12-gram 抓不到，只能人工
   - **同稿轻改**（换词重录）→ 4-gram/2-gram Dice 正负分布重叠，**不建议自动判定**
4. **没有女生版硬件评分表**（找到了 3 个矩阵号复述，但及格线需 6 项、当前最多判定 4–5 项，且核心账号复述为 0）。女生侧用工程默认权重，已标注。
5. **语料有效时长约 76.7 小时**（78.2h 扣回音 47 分钟）。回音率 3.0%，**但没有任何一条被引用的引文落在回音区内**。
6. **场次识别有缺口**：`≤3h` 是代理；同一场直播在两号各切一段且内容不重叠的情况无法检测（需原始直播 ID）。
7. **主张分类缺一类**：「建议型/方法型」未覆盖，少量规则临时归入 `market-norm`（见 `OPEN-QUESTIONS.md`）。

## 五、怎么让它变得更强（有标价的路径）

### 让「准确率」变得可测
| 做到哪一步 | 可评估案例 |
|---|---|
| 现状 | **0 / 45** |
| ＋ 表单允许 19 个自评/偏好项填「未知」（**已完成**） | 0 / 45 |
| ＋ 补语料 Top 12 字段 | **19 / 45** |
| ＋ 补 Top 14 字段 | **45 / 45** |

补的字段全是博主访谈里本就常问的（户籍/车/婚史/收入/院校/颜值自评/家庭出身/房/手足/学历/职业/身高/年龄/城市）。**这两步都不需要改引擎。**

### 让证据变强
只有一条路：**增加非矩阵来源**。同机构内部再怎么补语料，都只会增加同稿复述。

### 让女生侧对称
需 ①扩大表单字段（储蓄档/恋爱史/社保连续性）②裁定存款与恋爱史冲突 ③明确「正经工作」判定 ④争取核心账号权威复述。清单在 `knowledge/composite-criteria.female.md`。

## 八、这个系统的能力边界（一句话）

> 它**不能**告诉你「你值几分」。
>
> 它**能**告诉你——
> 这一句有 3 个账号说过、但都是同一家机构；
> 这一句只有 1 个人说过一次；
> 这一句的数字你可以自己去国家统计局查；
> 这一句是博主自己的评分表，不是行业标准；
> 这一句是某场活动的报名门槛，不是市场规律；
> 这一句是我们编的，没有依据；
> **而这个系统的结论对不对，我们测不出来——需要你自己看。**
