## 1. 城市差异（逐城市）

### 1.1 北京

1. **本地匹配偏好强**，且本地专场按城区/户口设置准入；跨城或非本地户口会增加匹配成本（R-DEMO-001，可执行）。
   - 语料：「北京土著找土著有执念……而且我觉得哪都都是本地人优先找本地人。」— aoye98 / 7640420395706862889
   - 语料：「在北京我们有个城六区土著专场，身份证号 110101 到 110108，您就能参加。」— aoye28 / 7689440280184917258（ASR 原文"城陆区屠住"）
2. **年龄劣势可用"放宽城区"补，但户口不放**：老北京人可接受从城六区退到门头沟等郊区，但要求户口；同时"别卡独生子"。
   - 语料：「年龄大个 7 岁，老北京人不要要求成六区（城六区）的，找个就是比方说门头沟的，有户口的，然后别卡独生子。」— aoye98 / 7640076462543867176
3. **A8 男供需数据是单条估计**（"在北京适婚的 A8 男只有几千个"），来源单一、属估计值，**不进入任何计算**，只作背景。
   - 语料：「在北京适婚的 A8 男估计只有几千个，但想找 A8 男的女生估计都有大几十万个。」— 47590488570 / 7625983656905404337

### 1.2 上海

1. **土著有房专场准入口径**（claimType=**event-rule**，来源：月老鳌烨·上海土著有房专场；仅代表该主办方，非当地普遍门槛）：身份证 310 开头，或已在上海购房（S-DEMO-001；R-DEMO-002 可执行）。
   - 语料：「只要您身份证开头是 310，或者说您已经在上海购置了房产，就可以来参加。」— aoye98 / 7636699793313598729
2. **同城匹配的现实收益**（活动方口径）：减少住房、子女教育、赡养安排上的不确定性；资产同城叠加。
   - 语料：「第一点呢，是你不用过多的考虑赡养父母以及孩子教育投入的问题。第二点呢，是你不用规避风险。第三点呢，是不用考虑住房、买房压力。」— aoye98 / 7639306639819951395

### 1.3 深圳

1. **土著有房场准入口径**（claimType=**event-rule**，来源：月老鳌烨·深圳土著有房场；仅代表该主办方，非当地普遍门槛）：身份证 4403 开头，或已在深圳购房（S-DEMO-002；R-DEMO-003 可执行）。
   - 语料：「因为我们这边的条件其实是身份证号 4403 开头，或者是在深圳买房。」— aoye98 / 7640036505334877491
2. **移民结构**：深圳是移民城市，本地专场规模显著小于北京、上海。
   - 语料：「深圳毕竟是一个比较新鲜的城市，大家大部分都是外地人。所以说这个深圳土著场的话，它人肯定是不会太多的。」— aoye98 / 7640036505334877491
3. ~~包容度较高、更看能力与规划~~ → **claimType=marketing**（来源：月老鳌烨深圳说媒招募视频）：这是同一机构 3 条招募视频里的获客话术，不能读成"深圳市场就是这样"；已改为 advisory，不作规律输出（R-DEMO-004）。
   - 语料：「深圳这边男生对女方他没有太多的硬性要求。一般就是性格好，原生家庭完整，这个比较重要。」— 47590488570 / 7672727361784562609
   - 语料：「深圳……很看重你的个人能力，以及未来的一个能力规划。」— 47590488570 / 7682641580730634225
4. **男女报名比 1:1.5（女多男少）**为单场活动数据（aoye98 / 7641872702176759076），只作现场信息，不构成市场规律（未进入规则层）。

### 1.4 杭州（单源，advisory）

> 以下来自 1 条语料（aoye98 / 7668215556251634959），**已标 advisory，不自动渲染**；等语料补全后再考虑升级。

1. **产业结构**：电商、带货、直播、MCN 相关产业密集，相关从业者多、外来人口比例高（只保留产业/供需结构描述）。
2. **男方对职业的顾虑**：部分高收入男生对"学历/技术门槛不高、主要靠外貌变现"的职业有顾虑（属个人偏好，不是对职业的评判）。
3. **大厂技术岗溢价**：大厂顶级技术岗（算法、架构等）与高学历、高收入组合被本地部分女生看重。
4. 江浙沪内部仍有城市级差异，不能合并处理（R-DEMO 层面未设规则，见 03）。

### 1.5 宁波（单源，advisory）

- 当地恋爱时间与金钱成本较高、更看综合价值（R-DEMO-038，advisory）。
  - 语料：「不是宁波没有爱情，而是爱情在这里多多少少有点像奢侈品。」— 33349790582 / 7685430909835876837

### 1.6 南昌

1. **高净值活动里，女生筛的是综合素质**：在颜值差不多的情况下更看学历、家境、教育环境、工作。
   - 语料：「其实我们更看重的是一个女生的综合素质，在颜值差不多的情况下，我们更注重你的学历啦，你的家境啊，然后你的教育环境啊，包括你的工作。」— 47590488570 / 7669651629650646267
2. **产业结构相对单一**（水泥搅拌站、食品加工厂、加盟酒店等传统行业为主）。
3. **彩礼**：彩礼/陪嫁被当作小家庭的启动资金（R-DEMO-018/019 可执行，按城市能级分支）。

### 1.7 长沙

1. **活动口径**（claimType=**event-rule**，来源：月老鳌烨·长沙优秀青年局；仅代表该场活动）：女生年龄卡在 30 岁以下，男生卡家境与收入（S-AGE-001；R-DEMO-005 可执行，标注为活动口径）。
   - 语料：「男生呢，我们依旧会卡下家境，然后收入。女生呢，卡 30 岁以下。」— 47590488570 / 7650118291364764794
2. **城市结构**（单源，未进规则层）：年轻、烟火气足，工程/汽车/文化信息产业较发达（47590488570 / 7692340853491662217）。

### 1.8 郑州（单源，advisory）

- 报名者更常问"想不想结婚、稳不稳定"；行业覆盖广（国企/教育/央企/医疗）但创业少（R-DEMO-034，advisory）。
  - 语料：「但郑州问的最多的人就是：他想不想结婚？有没有步入家庭建设的意愿？他这个人稳不稳定？」— 47590488570 / 7682641580730634225

### 1.9 山东 / 青岛

1. **精英群产品线口径**（claimType=**event-rule**，来源：月老鳌烨·精英群产品线，跨城市复用）：女生 98 后（部分地区写"28 周岁以内"），男生 90 后高净值（另加年收入 10-50 万或房车全）。**完整语料确认这不是山东独有**——山东（济南/青岛/淄博/泰安）、东三省（沈阳/哈尔滨/大连）、福州、山西（长治/大同）、南宁都是同一模板（R-DEMO-006，machine 城市列表已扩展）。这是产品线报名规则，不是当地市场规律。
   - 语料：「男生的门槛还是 90 后高净值，女生的门槛还是 98 后。」— aoye98 / 7643773318034843603
2. **青岛/山东的城市气质**（单源，advisory）：偏传统稳定，更看重建立家庭后的生活掌控感（R-DEMO-035）。
   - 语料：「那我们山东呢，一直都是偏传统稳定发展的……大家更希望跟对方去组建家庭的时候，我们的生活是有掌控性的。」— 47590488570 / 7688079473736914609
3. **省内异地接受度**（soft，未进规则层）：山东接受省内城市互认；河北、山西存在指定城市不互认（S-DEMO-005）。
   - 语料：「在我接的所有咨询里，山东人最能接受本省异地恋……济南也行，青岛也行，烟台也行。」— aoye98 / 7643773318034843603
   - ⚠️ 同条 ASR 地名需修正：**"泰州"应为泰安、"资博"应为淄博、"围房"应为潍坊"**（P2-10）。
4. §v1 中的"山东颜分局名次→可达上限"表已**删除**：审计判定为 n=1 个案外推 + 大小池混用（35 人池 / 40 人池），现归 03-matching-rules 的 advisory 处理。

## 2. 地域通用规则

1. **本地人优先找本地人**（跨城通用，R-DEMO-001/002/003 的公共前提）：三城都设本地专场，准入按身份证前缀或本地购房；理由口径是降低风险成本（教育、住房、远嫁）。
2. **城市能级加分**：新一线以上且本市户籍构成加分项（S-DEMO-006；R-DEMO-020 可执行）。
3. **彩礼随城市能级变化**（R-DEMO-018/019 可执行）——语料只给出方向（大城市更偏象征性、县域更偏保障），不构成金额标准。
