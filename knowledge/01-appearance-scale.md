## 1. 分数制与边界

1. **1–9 分制、0.5 分一档，男女各一套标尺。**
   - 「1-9分的外表男生评价提起来咯。」— 47590488570 / 7664928566988175995（该条转写后半段卡在循环，只剩标题句，正文缺失）
   - 实测出现过的分值：3.5、4、4.2、4.5、4.6、4.7、4.8、4.9、5、5.1、5.2、5.3、5.4、5.5、5.6、5.7、5.8、5.9、6、6.2、6.3、6.5、7、8.5。**语料中未出现 1–2.5 与 7.5–8.4 的博主锚点。**
2. **打分本质是排名**：博主不打"绝对分"，而是先把人放进「100 个人」的池子里给位次，再折算成分。比较池是同龄人。
   - 「4分是中位数，这你能知道吧，颜值偏态分布。」— aoye98 / 7651589852420427048
   - 「咱就是说95年，不要和年轻人比啊……95年里100个人里，这样不是前30，没问题。」— aoye98 / 7654913599751654708
3. **3–4 分 = 普通人区间**，4 分往右开始脱离普通。
   - 「三到四分是普通人吗？对。四分往右一点点。」— aoye98 / 7648982262922382646
   - 「敢颜值怎样？正常人吧，3.5左右吧。」— aoye98 / 7639325798792482102
4. **5.5 分是第一个"好看"门槛**，被明确称为"能吃到颜值红利"。
   - 「能找，颜值5.5分就是已经能吃到颜值红利了。」— 41252723284 / 7550417741316934962
5. **6 分是"百里挑一"**，也是博主直播里"能开摄像头（露脸连麦）"的门槛。
   - 「六叫班草叫百里挑一。」— aoye98 / 7640420044572282158
   - 「6分就是全班比你是最帅的那个，百里挑一。」— aoye98 / 7646730995613355327
   - 「原来只是6分能开摄像头。」— aoye98 / 7653425487565360436
6. **7 分要求原生**；可达性存在跨账号冲突：aoye98 认为几乎不可达，aoye28 多例直接给 7 分（S-LOOKS-011 conflict，不得跨账号混用）。
   - 「全中国就你一个男生，你也不可能是7分。」— aoye98 / 7644902230331542826
7. **8.5 分 = 国花国草。**
   - 「娱乐圈女明星谁能上8.5？8.5就是国花国草。」— aoye98 / 7661209960478444827
   - aoye28 入库后新增定义：「一千万个人里出一个的颜值」（S-LOOKS-013，定义型表述，无计算阈值）
8. **同一张脸存在"广义分"与"地方分"两套口径。**
   - 「兄弟我就这么说，广义场的6分他没达到，狭义场在珠海的6分能达到。」— aoye98 / 7661210006183824678（单条，低置信；地域细则归 04-demographics.md）

## 2. 各分档的可观察特征（原始证据）

### 3–4 分：普通人
- 4 分是中位数，偏态分布；博主会直接说"咱就是正常人的长相"（aoye98 / 7651589852420427048）。
- 「三到四分是普通人」；博主对自称"四分左右"的来访者回答"四分往右一点点"（aoye98 / 7648982262922382646）。

### 4.2–4.5：普通偏上
- 女，06 年生、1 米 79、55kg："再上身高，我能给您打4出头，就比普通人给您强……4.2差不多有了。"（aoye98 / 7661209960478444827）
- 女，02 年生、1 米 62、55kg：4.2，"100个女生里前40名，没问题"（aoye98 / 7653425487565360436）
- 女，03 年生、1 米 62、40kg："身高稍微一丢丢减分，干净五分不错啊……4.6"（aoye98 / 7647499397491674404）
- 男，1 米 83、160 斤：4.6，"100个男生里，第23、第22"（aoye98 / 7655981256437517602）

### 4.6–4.9：宿舍花 / 舍草层
- 「这就叫标标准准的小舍花。一个宿舍里有争议的那个舍花。4.7、4.8差不多。」（aoye98 / 7650475626062810422）
- 「能争一下宿舍舍花？……4.7，差不多。」（aoye98 / 7650833393881533731）
- 「有争议的宿舍舍花差不多就是8个人里7个人里出一个，就4.8、4.9。」（aoye98 / 7656400717271354624）
- 男，01 年生、裸身高 1 米 82、75kg：4.9，"100个男生里的21，能争下宿舍舍草没问题"（aoye98 / 7649352622561824019）
- 男，31 岁、1 米 87：4.8–4.9，"100个男生里前30"（aoye98 / 7654913599751654708）

### 5.0–5.3：无争议的宿舍花 ≈ 有争议的班花
- 「没争议的就是5分出头了……你要说没争议的宿舍舍花，基本上就跟有争议的班花就是一个水平了，就是5.2到5.3。」（aoye98 / 7656400717271354624）

- 男，1 米 62、145 斤来访者被评"颜值是门票"（aoye98 / 7639676121834851593）

### 5.5 分：有争议的班花班草 / 无争议的校草（首个"好看"门槛）
博主给出的**文字版男生 5.5 分标准**（可当 checklist 用）：
> 「5.5分就是有争议的班花班草。就是群雄割据的班集体里面，没有公认的那个班花班草在那个位置，那就是班花班草。我说一个文字版的颜值男生5.5分吧。光脚1米80，五官不能有硬伤，会穿搭，身材好，皮肤好，基本上就算5.5分了。不能有硬伤，就是三庭分布，比方说它的眉眼唇，它的牙弓比例，头肩比，面部折叠度，不需要多么出色，都组合起来没问题，这就叫5.5了。」
> — aoye98 / 7640777429912538409

- 「5.5分就是有争议的班草、无争议的校草。100个人里保八成五吧。」— aoye98 / 7656724726068301062（"保八成五"含义存疑，未采用为百分位）

## 4. 男女标尺是否不同

**不同，且是两套独立标尺。**

1. **同等待遇所需分数差 0.8**：
   > 「女生我觉得4.5以上干净一点就能收到搭讪（ASR：按理按时）。男生起码得高0.8分。」
   > — aoye98 / 7641867771478822185
2. **两侧的好看密度不同**：
   > 「100个女生，你起码能找到30个好看的女生……但是100个男生中5个长得（帅的）……帅个就是20里面的挑一个。」
   > — 47590488570 / 7660054519484591217
3. **同样分数落到百分位不同**（语料交叉，均为单账号口径）：女 4.6 与男 4.6 在各自性别池里的位次不同（aoye98 / 7647499397491674404、aoye98 / 7655981256437517602）；女 5.7–5.8 与男 5.3 的百分位也不同（aoye98 / 7650107302800018724；47590488570 / 7627766660082953083）。按 D6，对外位次一律用区间口径、禁止单点；本节保留的原话数字只用于说明口径不一致，不得进入规则或文案。
4. **"男女对颜值的要求不一样"** 被博主作为与来访者争论时的方法论前提直接说出（aoye98 / 7639325798792482102）。
5. **男女身高口径都发散**：女 1 米 79 被称"超模身高……优势"（aoye98 / 7661209960478444827），但同账号还有 162 小幅减分、aoye28 另有 172/174"黄金身高"——多口径并存，不设女性身高门槛（S-HEIGHT-008 已降 soft）；男性则是不进入 6 分档的概念封印，同样不设统一数值上限（S-HEIGHT-003/009）。
6. **矩阵号口径**：南昌号认为女生真实择偶排序是身高 > 颜值 > 收入…（48854385344 / 7693167762713201929）——属择偶偏好维度，不是评分标尺本身，交叉参考。

> 置信度：中。直接对照的语料只有 3 条（2 个账号），"0.8 分差值"只在 1 条里出现。

## 5. 原生脸 / 整容 / 素颜

1. **7 分档强制核验原生**：「你脸没动过是吧？你的脸有动过吗？是原生的吗？……你要说纯天然的，真的是有7分。」（aoye98 / 7644902230331542826）——即申报 7 分时，博主先捏鼻、问是否动过刀，确认纯天然后才认可。
2. **素颜只作为申报口径，不作为判分依据**：来访者说"素颜5.5分/素颜6分状态好有6.5"，博主均当场复核并否认——「咱这素颜可不是5.5分，姐妹」（aoye98 / 7638137159593053486）、「咱俩可没6.5啊，素颜6分也没有」（aoye98 / 7646730995613355327）、「素颜5.5分那还上头来」（aoye98 / 7654160476187741466）。判分看的是画面里此刻呈现的样子。
3. **医美/整容的扣分规则目前无有效证据**：全库检索"整容/医美/整形/打针"命中 0；唯一疑似是「咱刚做完肋骨鼻」（aoye98 / 7655272500171001130），该条上下文自相矛盾（随后又说"我没动啊"），不足以得出结论，已列入 OPEN-QUESTIONS。
4. **美颜/滤镜被视为判分干扰项**而非加分项：「会拍照，找角度，会开美颜，你觉得自己就是顶美了吗？」（48854385344 / 7682020548599172403）
