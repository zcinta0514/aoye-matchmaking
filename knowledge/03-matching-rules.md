## 0. TL;DR（给网页引擎的 10 条核心结论）

1. **婚恋画像 = 输出一个“具体到可执行”的目标对象**（不是形容词），格式固定：城市/本地性 · 独生与否 · 身高体重 · 颜值分 · 学历 · 职业 · 收入 · 家庭结构/资产 · 性格短板 · 婚恋诉求。结论句是“**你是他的心智首选 / 第一选择**”。{aoye98 / 7649728311765060883}
2. **心智首选（≈ 对方的 plan A）**：在你指定的目标类型里，你排第一顺位；**边界检验**是“再往上加一档条件，对方就‘不考虑咱了’”。{aoye98 / 7649728311765060883、aoye98 / 7635221339149765926}
3. **上限（天花板/极限）** = 你能触达的最优对象，通常由“颜值位次 + 资产档位 + 城市”决定；**触发语**：“就是你的天花板了”“绝对的上限”“极限”。{aoye98 / 7637107374934838571、aoye98 / 7635580597229849866}
4. **稳妥区间 = 画像本身**（你能当对方第一选择的那一类人）；**下限 = 保底底线**（必须保住的 5–7 项，不能再破）。同一个词“下限”有两种用法，注意区分。{aoye98 / 7649728311765060883、aoye98 / 7639325798792482102}

## 1. “婚恋画像”是什么

### 1.1 定义（原文级）

- 博主给来访者当场口述一段“目标对象”的描述，然后定性：“画像我给您画的，你是他的心智首选”、“你是他的第一选择，这叫婚恋画像”。{aoye98 / 7649728311765060883}
- 画像这个词还有第二层用法：指**来访者本人的择偶定位**（“我的一个画像……我的分大概人在几分”）。{aoye98 / 7635976663062433034}
- 画像会**按用途分叉**：“找女人的画像和找老婆的画像也是完全不一样”。{47590488570 / 7657819230796181371}

### 1.2 输入（博主现场问什么）

从 8 个完整流程看，输入清单基本固定：

| 类别 | 字段 | 例（原文） |
|---|---|---|
| 基本 | 年龄、身高、体重、颜值自评 | “我身高 1 米 73，然后 115” |
| 硬件 | 学历、职业/编制、收入、房、车、户口/本地性 | “本科学历，工薪家庭”“全款房”“月入 8K” |
| 家庭 | 父母职业/退休、资产档（A7/A8/A9）、独生/兄弟姐妹、原生家庭状态 | “父母同一个央企退休，家里面 A7.2” |
| 软性 | 社会化程度（会不会聊天）、性格、情绪价值供给 | “您确实社会化程度不太高……不太会八面玲珑” |
| 诉求 | 想找什么样、渠道、婚恋时间表 | “她想在两年之内把婚结了” |

### 1.3 输出（画像的固定格式）

输出不是“优秀/聊得来”这类形容词，而是一个**可被人肉检索的真人模板**，字段与示例：

> **例 1（女，01 年，县城体制内家庭硕士）**
> 来访者：2001 年独生女，父母体制内公务员（县城小领导），家庭幸福，“社会化程度不高”。
> 画像原文：“找个土著，独生子，1 米 72，140 斤，形象一般，房车全，211 本硕，体制内的事业编，不太会聊天，这路子考不考虑？”
> 定性：“画像我给您画的，你是他的心智首选”；边界：“他 1 米 8 就不考虑咱了”。
> {aoye98 / 7649728311765060883}

> **例 2（男，97 年，东北五线国企大专）**
> 来访者：97 年、1 米 85、80kg、大专、五线城市国企、月薪 8K、当地全款房。
> 画像原文：“找个本地人，独生女，1 米 68，颜值普通人，体重 110 斤，专升本的学历……在餐饮品牌做财务……月收入 3500 左右，学会计专业……物欲低一点……情绪也挺稳定，想在两年之内把婚结了……父母同一个央企退休，家里面 A7.2”。
> 附带门槛校验：女方“拿什么来补这个年龄”→ 男方可用“正式工作（五险一金）”补；不要求体面的话“普通国企也行”。

> **例 3（女，97 年，北京互联网运营）**
> 来访者：1 米 77、110 斤、本科、工薪家庭。
> 画像原文：“年龄大个 7 岁，老北京人不要要求成六区的，找个……门头沟的，有户口的，然后别卡独生子……能卡个身高，别卡颜值……区县委办局的公务员……性格内向一点，闷一点，不太会给女生提供情绪价值”。
> 附加取舍：不要求上进心、不要求浪漫，“踏实过日子可以，浪漫不行”；博主总结“它是一个翘翘板”。

> **例 4（男，宁波电商，本科，年入 15–20 万）**

> **例 5（女，00 年，济南硕士体制内）**

> **例 7（女，山东烟台猎头，30+）**
> 画像原文：“找个山大的本硕，比你大四岁，九四年，能要求山东人，能要求独生子。能要求他父母不离异，他父亲银行退休，母亲……央企退休，他俩有养老金、有退休金……男生能要求有个二十万的存款，不能要求情绪价值，不能要求外貌”（胖一点、1 米 78、180 斤）。
> 来访者嫌 180 斤，博主把目标降到 160 斤，但同步**收回一个准入项**：“工作要求不了体制内”。

> **例 8（女，00 年北京 211 本科，丁克）**
> 画像原文：“92 年比你大八岁，北京本地土著……也卡独生子。然后的话 211 本硕，在乡镇区办公务员。月收入 6000 到 8000，玩不到一块、聊不到一块。但是有全款的房子，对物欲没有太多要求，喜欢打打游戏。”

**格式归纳**：（城市/土著与否）+（年龄差）+（身高+体重）+（颜值分或描述）+（学历）+（职业/编制）+（收入）+（家庭：独生/父母退休/资产档）+（1–2 条性格短板/优点）+（婚恋诉求）。

### 1.4 “极限/天花板”写法（上限的画像）

- 02 年、石家庄、想找大 7 岁男友 → “95 年，专科，做剪辑/贷款，家里独生子，跟着妈妈，无负债，能做到尊重女性，就是你的天花板了”、“绝对的上限啊”。{aoye98 / 7637107374934838571}
- 04 年、中戏本科北京、父母小生意+公务员 → “极限啊……北京本地人，985 本硕，性格内向，不会给女生提供情绪价值，A8.2，独生子，在石景山当公务员，一个月收入 8000，家里面北京两套 800 万的商品房，还有点股票跟保险，但是我都怕这个路线你都拿不下。”{aoye98 / 7635580597229849866}

### 1.5 小结：画像的三条硬规则

1. **必须落到“谁 + 什么条件”，且给出年龄差与城市限定**（例 1/3/8）。
2. **必须同时说明“对方的短板”**（不太会聊天 / 玩不到一块 / 形象一般 / 胖），否则不成立（例 1/3/7）。
3. **必须配一条边界**：“再高一档就不考虑咱”（例 1）、“我怕这个路线你都拿不下”（§1.4 第二例）、“上嫁没戏”（§7）。

## 2. “心智首选 / 第一选择”的定义与判定

### 2.1 原文定义

- “画像我给您画的，你是他的心智首选”、“你是他的第一选择，这叫婚恋画像”。{aoye98 / 7649728311765060883}
- 同义表述：“你不是他的 plan A”（当某人不在对方第一顺位时）；“复制粘贴的你这三画像都能找，大家不会找您，或者说您不是他的 plan A”。{aoye98 / 7635221339149765926}
- 反向用法（负例）：海王型男生 “你不是让海王收心的心智首选”。{aoye98 / 7635221339149765926}

### 2.2 判定条件（从语料反推，v1 假设，待补语料验证）

对目标类人群 G，你是 G 的**心智首选**，当且仅当：

1. **G 的画像里包含你**：G 的刚需（年龄/身高/学历/职业/家庭）你能满足大部分；{aoye98 / 7649728311765060883、aoye98 / 7638583110027824447}
2. **G 在市场上拿不到比你更好的**：加一档条件（1 米 8、A8 家庭、颜值更高）后，G“就不考虑咱了”→ 说明你在 G 的可触达集里排第一；{aoye98 / 7649728311765060883、aoye98 / 7636008548790553907（“他家里边 A8 家庭，他不考虑你”）}
3. **你愿意主动**：多例画像附条件“你要主动 / 只要停止主动就 over”。{aoye98 / 7638160736476286234、47590488570 / 7625983931657628154}
4. **反检验（竞争池检验）**：把“比你小 7–8 岁、同画像的女生”放进池子，目标对象仍选你，才算；否则“镜像版的你”会赢走该对象。{aoye98 / 7636008548790553907、aoye98 / 7635221339149765926}

### 2.3 关键量化锚

- “你是他的心智首选”对应的目标必须**低于你的竞争上限**：1 米 72 的土著独生子 = 首选；1 米 8 = 不考虑。{aoye98 / 7649728311765060883}
- “镜像版的你竞争力比咱强呀……不是一个维度呀”——**同层对手（镜像版）通常有更多画像可选**：私企白领 6.5 分、高学历小美、好拿捏型三类都能找。{aoye98 / 7635221339149765926}
- 市场权力曲线：**腰部以下**（月入 2000、买不起房）“女生有绝对碾压式优势”；**中腰部**（月入 8000–9000、能出首付）仍偏女生；**超过腰部**（上海有房、A8 家庭）“到了男生有主动权的地方”。{aoye98 / 7635221339149765926}

### 2.4 未知/待补

- 判定“第一选择”没有给出打分公式（例如“当你 ≥ G 的可触达集 top1 即入选”只是反推）。**归属：本文件 v2 + 需 100% 语料复核**。

## 3. 择偶上下限：口径与操作算法

### 3.1 三种口径（必须区分）

| 口径 | 原文用词 | 含义 | 证据 |
|---|---|---|---|
| 上限 | 天花板 / 绝对的上限 / 极限 | 你能触达的**最优对象**（高于它就不看你） | aoye98 / 7637107374934838571、7635580597229849866 |

**B. 资产档（家庭资产尺子）**

- A8 = 净资产 1000 万以上（含车房、股票、基金、现金）；A9 的圈子“普通人根本进不去”；A7 被很多女生认为“太普通”、高不成低不就。{47590488570 / 7625983656905404337}

- 现场成交例：A7.2 = 独生女 + 父母央企退休 + 全款房车的画像；A8.2 = 北京两套 800 万商品房+股票保险。{aoye98 / 7638583110027824447、aoye98 / 7635580597229849866}

**C. 硬件打分制（男口径，10 项 × 10 分，60 及格 / 80 优秀）**

> 身高 1 米 75 以上 +10；全日制本科以上 +10；房 100 平以上或全款 +10；有车 +10（20 万以上或全款再加 10）；年收入税后 10 万以上 +10；新一线以上稳定工作或本市人 +10；体制内 +10；父母有退休金养老金 +10；独生子女 +10；原生家庭幸福 +10。
> {47590488570 / 7617107297344810085}

**D. 前置条件：城市**

- “婚恋这个话题的前置条件一定是城市。就不同的人在不同的城市，它的竞争力是不一样的”；换城市“元气成本极高”。{aoye98 / 7635962961365880074}

> “在宁波找对象就记住四个字。反向匹配。”
> - 长得不错但原生家庭普通 → 找“外形中规中矩，但家庭基础稳定、关键时候能兜底”的人＝**用外形优势换对方的生活包装**；

> - 考上编制但工资低 → 找经商家庭（人家不缺生活费，缺稳当体面、能撑场面的女婿）；

> “拿你有的，换你要的，不要一手好牌烂在手里。”
