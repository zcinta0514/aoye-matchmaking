### 5.2 金额用「个」代「万」（63 处）

例："助力的话 20 个"（20 万）、"存款有 50 个"（50 万）。但同一写法也用于人数（"一年内谈了 20 个 30 个"），所以同样**只检测不替换**。

## 6. 循环回音（新发现的数据质量问题）

全库检出 61 处"同一句连续重复 ≥6 次"的转写回音，例如 30578719968/7551510893993987355 同一句重复 18 次。
这类区域会产生**虚假高频词**（如 aoye28 里的"词补巨×27"就是回音产物），任何词频统计都必须先剔除回音区。

## 7. 工具用法

`@bash
node tools/asr_normalize.mjs --check            # 变体命中复核（raw / applied / UNUSED）
node tools/asr_normalize.mjs --numbers          # 数字噪声检测（新增）
node tools/asr_normalize.mjs --numbers --json   # 机读版
node tools/corpus.mjs search "校草" --normalize --ctx 1 --limit 2   # 检索召回
node tools/corpus.mjs search "校草" --normalize --fix --ctx 0 --limit 2  # 输出纠错 + [原:错字→正字]
`@
