## 0. 他实际用的分类词（不是「硬件/软件」）

| 结论 | 原话 | 证据 |
|---|---|---|
| 语料中**「硬件」零命中**，实际用语是「硬性（门槛/指标）」与「软性」 | 「这些**硬性的门槛**，我们帮你们拔好了。剩下的**软性的**，大家就在互相认识的过程当中慢慢了解」 | 47590488570 / 7688079473736914609 |
| 硬性=事前可验证的条件，软性=相处才知道的部分 | 「硬性的东西，我们帮您稍微把关了。那到现场来说的话，我们只需要看大家聊不聊得来」 | 47590488570 / 7672727361784562609 |
| 硬性指标只能取舍不能全要 | 「你只能选一个**硬性指标**去三选，剩下的部分你也得认了」 | 48854385344 / 7684219597406342427 |
| 三件套叙事：情绪价值 / 经济价值 / 陪伴价值 | 「一个人他能给出来的就三样，一个是情绪价值、经济价值和陪伴价值。这三样，一个人也只可能占到一项大头」 | 48854385344 / 7684219597406342427 |
| 男女两套门槛 | 「**男生相亲的门槛是收入，女生相亲的门槛是颜值**」 | 48854385344 / 7684483743582637331 |
| 外貌在前置位（1/0 结构） | 「女生的外貌会是前置条件，相当于数字前面的 **1**，家境、性格、学识、个人能力等，都是后面的 0」 | 48854385344 / 7681616361696595209 |

**体系骨架图（本 Worker 综合）**

```
硬性条件（可量化、先筛）── 硬件：身高 / 学历 / 职业编制 / 收入 / 房车 / 户口
                        ── 外形门票：颜值 / 身材体态 / 形象打理（女性=1，男性=被低估加分项）
                        ── 家庭：父母职业 / 退休金 / 资产量级 / 家庭氛围 / 独生 / 兄弟姐妹
软性条件（相处才见）──── 性格 / 情绪稳定 / 情绪价值 / 沟通与社会化 / 生活方式 / 消费观
其他 ────────────────── 婚史（带孩再婚的匹配周期更长）
```

## 2. 逐维度要点（含原话）

### 2.1 硬件类

**身高（dim.height）**
- 男 175+ = 评分表 +10 分；1 米 75 在直播间「不敢说 6 分以上」，1 米 88/140 斤/五官端正 = 5.3 分（100 个男生前 20）→ **身高是男性颜值分的封顶器**（47590488570/7627766660082953083；aoye98/7639291023436369190）。
- 基数：全国男性平均 169.7，1 米 8 以上约 5%，1 米 85 不到 1%（47590488570/7625984741712386426）。
- 女性：向上链中男方普遍卡 **165 以上**；1 米 79 是「超模身高」纯优势，「别胖就行」（33349790582/7688292683130892197；aoye98/7661209960478444827）。
- 高个专场：个子够高可加约 **0.5 分**（aoye98/7641872702176759076）。

**体重/体型（dim.weight）**
- 博主口径把体重列为高影响减分项；原始等价表述按伦理策略不再复述（见 R-DIM-009 内部说明与证据 47590488570/7622657378560211641）。
- 双标：1 米 62/145 斤、1 米 73/135–145 斤都会被判胖；而 1 米 68/100 斤、1 米 65/110–120 斤在画像中正常（aoye98/7639676121834851593、7637831090509466906、7638583110027824447）。
- 男 1 米 75/180 斤 = 「稍微油腻一点」，竞争不过形象干净的（47590488570/7682641580730634225）。
- 唯一乐观点：体重是可改变项，减重是可执行提升路径（aoye98/7637831090509466906）。

**学历与院校（dim.education / dim.school_tier）**
- 评分线：全日制本科以上 +10 分；专升本/大专降档，仅顶美可豁免（47590488570/7617107297344810085；48854385344/7682020548599172403）。
- 高档锚点：211 本硕（aoye98/7649728311765060883）、山大本硕（7636352944786509094）、985 读博（7637831090509466906）。
- 反向观察：一位体制内男性对「第一学历 985/211 + 独生女」的女生说「学历太高，我有点害怕」（aoye98/7639325798792482102）——高学历对女性不是无限加分，需与男方能级匹配。

**职业与编制（dim.occupation / dim.establishment）**
- 城市样板（太原）：「最香的肯定还是编制。有行政编、事业编、企业编」；行政编=公务员，事业编=教师等；稳定生意（年入三五十万）也吃香（25845559030/7367266582898183439）。
- 男方体制内 +10；**女方编制不构成核心竞争力**：「吸引优质男的从不是你那稳定的几千块钱一个月收入」（47590488570/7621886143206349221）。
- 杭州特例：收入高的男生介意女方「学历/技术门槛低、单靠颜值变现」的职业（aoye98/7668215556251634959）。
- 隐藏事实：杭州、三亚等报告显示，活动现场「女生考编制的居多」，编制在女性内部是竞争项而非加分牌。

**收入（dim.income）**
- 评分表：税后年入 10 万+加 10 分；一线/新一线「稳定工作或本市人」另加 10 分（47590488570/7617107297344810085）。
- 强势线：二三十万「秒杀 90% 以上竞争者」；30 万以上，其他维度「差不多及格就行了」（20090777434/7509097036177902863）。
- 城市口径：太原月入 5000 已合格、年入 10 万中上等、体制内税后 10 万+「非常吃香」（25845559030/7370263231828495656）。
- 职业换算见 §3。

**房产 / 车（dim.property / dim.car）**
- 房：100 平以上或全款 +10；「有住房不用自己还贷款」=「真正条件好」三要素之一。北京案例量级：商品房+老破小约六七百万（47590488570/7617107297344810085、7641901227777451259；aoye98/7640076462543867176）。
- 车：有车 +10，20 万以上或全款再 +10；百万级汽车、开 BBA 的小老板出现在 A8 画像（47590488570/7617107297344810085；48854385344/7678636676851256618；aoye98/7648625116548533547）。
- 南昌口径：「超一间城市房子就是彩礼」→ 高房价城市的房权重被单独放大（47590488570/7669651629650646267）。

**户口/本地属性（dim.hukou）**
- 「北京土著找土著有执念」「本地人优先找本地人」；机构办「土著有房场」，深圳的筛选口径是身份证 4403 开头或在深买房（aoye98/7640420395706862889；47590488570/7640036505334877491）。
- 户口可降级配置：「老北京人不要要求城六区的，找个门头沟的、有户口的」——户口是硬项，区位是弹性项（aoye98/7640076462543867176）。

### 2.2 外形类

- **颜值**：女性=门票与 1（见 §0）；男性=「最被低估的加分项」——100 个男生中看得过去的约 5 个，20 里挑 1（47590488570/7660054519484591217）。顶美可让 A8 男生下调学历与家境门槛（48854385344/7682020548599172403）。
- **身材/体态**：「高个子的男生和身材好的女生相比，真的稀缺很多」；美女构成 40% 自信体态 + 20% 身材比例与穿搭 + 15% 发型妆容 + 剩余才是五官；体态可训（47590488570/7625984741712386426；48854385344/7682010628554231090）。
- **形象打理**：收拾干净 +5，是见面前三分钟的底线；「有头屑、体味、口臭会大幅度减分」（48854385344/7686783751560416531、7681986355500453158）。

### 2.3 软性类

**性格（dim.personality）**
- 30+ 事业有成的男人择偶排序**第一位永远是性格好**；性格好被认为比颜值更稀缺，装得了一阵装不了一辈子（47590488570/7681981213879522299；33349790582/7685706222226330085）。
- 男方红线：「只要你性格强势，那这个男生就不会和你有结婚的想法」——与漂亮、身材、收入、学历无关；能力强势可接受，性格强势不可接受（47590488570/7633323714143273979）。
- 性格的溯源：看他对父母怎么讲话、对服务员什么脸色（33349790582/7685706222226330085）。

**情绪稳定 / 情绪价值（dim.emotional_stability / dim.emotion_value）**
- 画像里可提的要求：「脾气稍微好一点点」；情绪稳定=不发无名火（aoye98/7638583110027824447）。
- 权衡关系：「能给你提供情绪价值的人，情绪都不稳定；情绪稳定的人，相对来说无趣一些」（aoye98/7638583110027824447）。
- 三价值：情绪/经济/陪伴只能占一项大头——体制内=陪伴价值，创业=经济价值（48854385344/7684219597406342427）。

**沟通/社会化（dim.communication）**
- 「沟通能力不是表达能力。你得知道对面的人他想要什么，他想在这置换什么，你准备付出什么，你能牺牲什么」（aoye98/7637428832835833134）。
- 行为计分：有来有回 +10；等对方找话题 −10；一坐下查户口（收入/房/父母）−15；把前任挂嘴边 −20（48854385344/7686783751560416531；33349790582/7686806385938325221）。
- 「社会化程度不高」意味着本分岗（财务等）适配、「不太会八面玲珑」（aoye98/7649728311765060883）——在画像中可作短板报出，但会限制向上匹配。

**生活方式 / 消费观（dim.lifestyle / dim.consumption）**
- 爱好本身不加分，能转化为双方受益的能力才加分（旅游为例：会规划路线、控预算、照顾同行感受才算）（48854385344/7681320477519924515）。
- 消费观看「花钱是否均匀」：一顿阔绰、下月紧缩=硬撑；一年到头差不多=真有底子（48854385344/7689034774287109395）。
- 减分信号：「月薪三千还天天下午茶」；「爱打卡网红店」被与「纹身喝酒抽烟」并列（47590488570/7638546961003941285，ASR 严重、low）。

### 2.4 家庭类

- **父母 > 自己**：「在整个婚恋市场上，父母优秀要比孩子优秀更加重要」「本质上拼的还是原生家庭」；最吃亏的是「自身优秀但家里没有资源人脉」的人（47590488570/7683097195286429625；48854385344/7682726879274503475）。
- **退休金是硬条件**：有退休金/养老金 +10；「没有养老保险，不管条件多好都算不好」；向上链中男方也要求女方父母有退休金（47590488570/7617107297344810085、7641901227777451259；33349790582/7688292683130892197）。
- **资产量级**：A8=净资产 1000 万+；A7 被嫌「太普通」；案例出现 A7.2/A7.5（47590488570/7625983656905404337；aoye98/7638583110027824447、7648981216003214611）。但「人家公司多大、房子多少，跟你有什么关系」——要能转成小家庭每月可用的钱（47590488570/7641901227777451259）。
- **家庭氛围**：原生家庭幸福 +10；检查项=没有强势的妈妈、没有醉酒的爸爸、父母不离异、全力托举女儿（47590488570/7617107297344810085、7635193382863706618；aoye98/7636352944786509094）。原生家庭不好的女生被建议「婚前守住家里所有的不堪」（48854385344/7681960174344621312）。
- **独生与兄弟姐妹**：独生子女 +10；「姐姐出嫁了，你也不是独生子」；「男生要求独生女」=看似没门槛、实际很高（47590488570/7617107297344810085、7668958682801423099；aoye98/7638160736476286234）。有弟弟会被审查，但明确的家产安排（一半一半）可抵消（41252723284/7550418120528203017；aoye98/7648625116548533547）。
- **城乡根基**：农村出身 + 家里无助力，在案例中直接导致对方父母切断关系（aoye98/7637831090509466906；48854385344/7687565236722879790）。

### 2.5 婚史（其他）

- 带孩再婚在语料中被认为需要更长的时间线（单例，30578719968/7551886955248733474）；原始措辞按伦理策略不作为用户可见文本。
- 机构活动设「离异区」，说明离异与带孩群体客观存在（47590488570/7643001454945425777）。

## 7. 冲突与不确定

1. **有弟弟**：一条语料把有弟弟当降配项；另一条显示家产明确（一半一半）时影响被抵消 → 非直接矛盾，写为条件依赖（R-DIM-026）。
2. **情绪价值 vs 情绪稳定**：同一条语料承认两者互斥（R-DIM-031、C13）——意味着「又要情绪价值又要情绪稳定」在博主体系里是加价项。
3. **门槛活动的性别标准 vs 个体偏好**：机构口径「男卡家境收入、女卡颜值+其一」是**筛选门槛**；而深圳活动话术又称「男生对女方没有太多硬性要求，一般就是性格好、原生家庭完整」——两者层次不同（机构 vs 现场配对），不冲突但不可混用。
4. **ASR 严重片段**：47590488570/7638546961003941285 的「婚恋市场潜规则对照表」错字密集，本文件只采纳可交叉验证的条目（体重影响系列），整表标 low。
5. **「硬件」一词**：本批语料 0 命中；可能是站外/直播口语或未转写部分内容。已在规则里保留「硬性条件」的说法。
